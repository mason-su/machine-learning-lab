# 这份整理包是什么？

这是从你上传的 `deep-learning-from-scratch-master.zip` 中筛选出的 **NLP 之前** 的学习、实验、模型和结果。没有上传整个教材仓库，也没有加入第二部书的 NLP 内容。

## 先看哪里？

- `README.md`：英文 GitHub 首页草稿、运行方式、数据说明。
- `FILE_SELECTION.md`：哪些文件是你主要做的，哪些是教材依赖，哪些没放进去。
- `FILE_MANIFEST.csv`：逐文件来源和新位置，包含原文件 SHA-256，便于追溯。
- `experiments/hyperparameters/`：你做过的超参数扫描及可视化。
- `results/hyperparameters/`：所有找到的超参数 CSV 和 **57 张原图**。
- `experiments/cnn/`：NumPy / PyTorch / CuPy CNN 以及模型分析。
- `results/checkpoints/`：保留了你压缩包里的 3 个模型权重文件，避免无法做权重可视化、错误分类和基线对比。

## 关于 150 组和 240 组

你的判断是对的：150 组配置全部存在于 240 组完整网格里，且对应的准确率、最佳 epoch 等指标 **完全相同**。唯一不一致的数值字段是耗时 `time_seconds`，所以原样保留两份，不擅自统一。150 组还有对应的逐 epoch 数据和 Loss；240 组有完整网格、汇总 CSV 和 57 张图。

**对应关系：**

| 代码 | 结果 | 数量 |
| --- | --- | ---: |
| `train_2.py` | `hidden_size_experiment.csv` | 8 |
| `train_3.py` | `hyperparameter_experiment.csv` 和 `hyperparameter_epoch_history.csv` | 150 / 2550 |
| 历史更完整的同一参数扫描 | `hyperparameter_plots/00_summary/all_results_ranked.csv` 及图片 | 240 / 57 张图 |
| `train_4.py` | `depth_width_experiment.csv` 和 `depth_width_epoch_history.csv` | 96 / 1632 |
| `train_5.py` | `depth_width_pattern_experiment.csv` 和 `depth_width_pattern_epoch_history.csv` | 54 / 918 |
| `cupy_loss.py` | `results/cnn/epoch_accuracy.csv` 和 PNG | 20 epochs |
| `cupy_myconvnet.py` | `results/cnn/cupy_training_timing.txt` | 1 次计时 |

## 为什么改动了部分代码？

为了让整理后的项目能从根目录运行，我修正了部分 `sys.path` 路径，并将 **新运行生成的 CSV、图片和模型** 改存到 `outputs/`，避免覆盖原始实验结果。还修正了 `train_5.py` 第一行缺少 `#` 的问题，并修正了练习版 `my_layers.py` 中 one-hot SoftmaxWithLoss 反向传播的 batch 缩放错误。其余主要算法和原始实验结果没有改动。具体见 `PACKAGING_CHANGES.md`。

## 重要说明

- 我没有重新训练所有模型；现有 CSV、图片和权重都是从你上传的 ZIP 直接复制。
- NumPy 基础模型和 CNN 前向计算可以进行本地小测试；CuPy GPU 训练需要你自己的 CUDA 环境，打包时无法实测。
- `experiments/learning_exercises/` 有教材改写练习，不能全部当作从零原创；`common/` 等教材依赖更不能宣称为自己的实现。
- 历史 240 组完整扫描对应的旧版 `train_3.py` 没有在压缩包中，因此目前无法保证从当前 150 组脚本逐字复现历史全部 240 组的运行条件。
- `results/checkpoints/` 是 pickle 文件，请只在信任来源的环境中加载。

## Windows / VS Code 开始方式

在新文件夹里打开终端：

```powershell
python -m pip install -r requirements.txt
python verify_results.py
python smoke_test.py
```

然后先查看结果，不必重新训练：

```powershell
python experiments/hyperparameters/data_visualize.py
python experiments/cnn/visualize_weights.py
```

**你可以先把这个文件夹作为私有 GitHub 仓库上传，检查 README、归属声明和运行效果，再公开。**
